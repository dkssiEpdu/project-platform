# SANTALYS Project Blueprint

## Project Overview
SANTALYS is a luxury, sensory-focused perfume and diffuser brand. The website aims to provide a minimal, artistic, and immersive digital experience inspired by modern aesthetic brands like Tamburins.

## Design & Style
- **Aesthetic:** Minimalist, high-end, sensory, and tactile.
- **Typography:** 
  - Headings: Elegant Serif (e.g., 'Cormorant Garamond' or 'Playfair Display') to evoke a sense of luxury.
  - Body: Clean, modern Sans-Serif (e.g., 'Inter' or 'Montserrat').
- **Color Palette:**
  - Primary: Off-white (#F9F9F9), Deep Charcoal (#1A1A1A).
  - Accents: Subtle Earthy tones (Stone, Clay, Sand).
- **Textures:** Subtle noise texture on the background for a premium, tactile feel.
- **Visual Effects:** 
  - Multi-layered soft shadows for depth.
  - Smooth fade-in animations on scroll.
  - Hover effects with gentle "glow" or scale transitions.
- **Layout:** 
  - Full-screen immersive hero section.
  - Asymmetric grid layouts for product showcases.
  - Clean, spacious navigation.

## Features
- **Immersive Hero:** A high-impact opening section with bold typography and atmospheric imagery.
- **Product Discovery:** Interactive product cards using Web Components for modularity.
- **Sensory Storytelling:** Sections dedicated to the "scent profiles" using evocative language and imagery.
- **Responsive Design:** Seamless experience across mobile and desktop.
- **Interactive Navigation:** Minimalist overlay menu or sticky transparent header.

## Current Implementation Plan
1. **Foundation:** Set up Google Fonts and basic CSS variables.
2. **Layout Structure:** Implement the semantic HTML structure in `index.html`.
3. **Styling:** Apply modern CSS (Baseline) for layout and aesthetics, including the noise texture and container queries.
4. **Interactivity:** Use `main.js` for scroll animations and Web Components for product elements.
5. **3D Elements:** (Optional/Future) Integrate Three.js for a signature 3D perfume bottle.
6. **Deployment:** Initialize Git (if not already) and push to the remote repository.
